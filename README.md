# 拾弦提琴工坊 · 展销会手机官网

面向乐器展销会的**纯静态响应式官网**：手机扫码即开、秒开、零依赖框架。深木棕/黑 + 米白/金 的克制配色，简约优雅，突出琴的质感。

## 快速开始

```sh
# 任意静态服务器即可，例如：
npx serve .          # 或
node server.js       # 本项目自带
```

打开 `http://localhost:8080`（或直接双击 `index.html` 也能看，但 JSON 加载建议走服务器）。

## 目录结构

```
luthier-site/
├── index.html          # 单页应用壳（hash 路由）
├── qr.html             # 展销会二维码海报页（可保存海报图）
├── css/style.css       # 全部样式（设计令牌化，改色只需改 :root）
├── js/app.js           # 路由 / 渲染 / 收藏 / 搜索 / 灯箱 / 分享
├── data/instruments.json   ← 所有琴款数据，日常维护只改这里
└── assets/img/         # 琴款图片（现为 SVG 占位线稿，替换成真实产品图即可）
```

## 数据维护（最重要的一节）

所有内容都在 `data/instruments.json`，**改数据即可，不用动页面结构**：

| 字段 | 说明 |
|---|---|
| `site.brandName` / `brandNameEn` | 品牌名（预留位置，改成你的公司名） |
| `site.tagline` | 品牌理念一句话 |
| `site.expo` | 展销会标题 / 日期 / 地点 / 备注 |
| `contact` | 微信号、电话、备注 |
| `series[]` | 三大系列：id / 名称 / 英文 / 描述 / 图片 |
| `tags[]` | 标签字典：id / 显示名 / 样式色（gold 金 / wood 木 / ink 墨 / outline 描边） |
| `instruments[]` | 每把琴：id / series / name / image / tags[] / params[]（键值对参数）/ price / note |

示例琴款：

```json
{
  "id": "v-01",
  "series": "violin",
  "name": "晨光 · 1716 复刻",
  "image": "assets/img/violin.svg",
  "tags": ["featured", "flagship"],
  "params": [
    { "k": "用材", "v": "欧洲云杉面板 / 波斯尼亚枫木背板" },
    { "k": "尺寸", "v": "4/4" }
  ],
  "price": "面议",
  "note": "斯特拉迪瓦里 1716 琴型"
}
```

- **新增琴**：复制一个对象改字段；**换图**：把真实照片放进 `assets/img/`，改 `image` 路径。
- **标签**：先在 `tags[]` 注册，再在琴的 `tags` 数组里引用；同一把琴可挂多个标签。
- 图片建议：宽高比约 4:3，文件控制在 200KB 内（手机上秒开）。

## 功能清单

- 首页：品牌名 + 理念 + 三大系列入口 + 展销会信息卡
- 系列页：按系列列琴款，支持**按标签筛选**
- 琴款详情：大图（点击放大）、参数表、价格/面议、微信/电话/分享
- 标签徽章：特别推荐 / 主打产品 / 特有 / 新到，样式精致不抢戏
- 收藏夹：心形收藏，存 localStorage，跨会话保留
- 搜索：琴名 / 系列 / 标签 / 参数全文筛选，即时出结果
- 顶部悬浮系列切换（滚动后出现）
- 图片灯箱放大（看细节纹理），懒加载
- 底部：微信 / 电话 / 一键分享 / 保存到手机（添加到主屏幕指引）/ 展销会二维码海报
- **网站内置内容管理后台**（见下节）
- 骨架屏加载态、空状态、错误状态齐全

## 网站内直接改内容（管理后台）

不想手改 JSON？网站自带管理后台：

1. 打开网站 → 页脚点 **「管理内容」**（或直接访问 `#/admin`）；
2. 输入口令 **`luthier2026`**（可改 `js/admin.js` 顶部的 `PASSCODE`）；
3. 四个页签分别编辑：**站点信息**（品牌名/理念/展销会/联系方式）、**系列**、**标签**、**琴款**（增删改、参数动态行、标签多选、图片预览）；
4. 点 **「保存」**，三种生效方式：

| 场景 | 保存后的效果 |
|---|---|
| 本机浏览器 | 立即写入 localStorage，刷新/重进即刻生效（仅这台设备） |
| 本地 `node server.js` 托管 | 自动写回 `data/instruments.json`，**局域网访客都可见** |
| 静态托管（Vercel / GH Pages） | 用 **「导出 JSON」** 下载 `instruments.json`，替换项目文件重新部署 |

另有 **「导入 JSON」**（换设备时导出后导入）和页脚「退出」；想彻底回到默认内容，在管理页把 localStorage 清掉（`重置` 或开发者工具删除 `shixian.data.v1`）。

> 注意：口令只防误入（源码可见），真正需要保护内容请加后端。

## 微信扫码访问（三种方式）

| 方式 | 地址 | 适用 |
|---|---|---|
| **公网隧道（临时）** | 运行 `start-tunnel.bat`，取输出的 `https://xxxx.lhr.life` | 立即让任意手机扫码（电脑需联网，地址重启会变） |
| **局域网** | `http://<电脑IP>:8080`（如 192.168.1.137:8080） | 展位同 WiFi 内扫码；需放行防火墙 8080 端口 |
| **永久部署** | Vercel / GitHub Pages 域名 | 正式方案，地址固定，推荐 |

生成海报：打开 `qr.html`（会自动编码当前地址）→ 「保存海报」→ 打印/投屏。微信扫一扫 → 直接打开网站。

## 部署（免费托管，扫码即开）### Vercel
1. 把本目录推到 GitHub 仓库；
2. [vercel.com](https://vercel.com) → New Project → Import 该仓库；
3. Framework Preset 选 **Other**，Build 留空，直接 Deploy；
4. 得到 `https://xxx.vercel.app`，手机浏览器访问即可；用该地址生成海报二维码。

### GitHub Pages
1. GitHub 新建仓库 → 上传本目录全部文件；
2. Settings → Pages → Source 选 `main` 分支 / root；
3. 访问 `https://你的用户名.github.io/仓库名/`。

### 展销会现场
- 用手机打开已部署地址 → 底部「展销会二维码」→ 得到海报页；
- 「保存海报」生成 PNG（品牌 + 二维码 + 展销会信息），打印或投屏；
- 观众扫码直达官网。

## 注意事项

- 字体走 Google Fonts（衬线 Cormorant Garamond + 无衬线 Outfit），无网环境自动回退系统字体；
- 二维码海报页的二维码库走 CDN（jsdelivr），离线时降级为「二维码图片 + 复制链接」，现场请在有网环境生成一次并保存；
- 纯静态、无后端、无统计代码，隐私友好。
